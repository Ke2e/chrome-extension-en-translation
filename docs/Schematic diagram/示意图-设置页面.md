# 设置页面（Options）—— 布局与实现步骤

## 1. 页面概述

设置页是用户在弹窗中点击"设置"后打开的独立标签页，宽度自适应浏览器窗口。所有配置项使用 Chrome Storage API 持久化存储，修改后即时生效。

## 3. 模块说明

### 3.1 AI 模型配置区

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| API Key | 密码输入框（`type="password"`） | 空 | 必填，用于调用 AI 模型 |
| API 地址 | 文本输入框 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | 必填，兼容 OpenAI 格式的端点 |
| 模型名称 | 文本输入框 | `qwen-turbo` | 必填，可选 qwen-turbo / qwen-plus / gpt-4o-mini 等 |

### 3.2 翻译设置区

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 系统提示词 | 多行文本框（textarea） | 内置默认提示词 | 可选，允许用户自定义翻译指令 |

### 3.3 关于区

展示插件版本和技术栈信息，仅用于参考，不涉及用户交互。

## 4. 设置页组件树

```
SettingsForm.tsx
├── AIConfigSection         ← AI 模型配置区域
│   ├── ApiKeyInput         ← API Key 密码输入框
│   ├── ApiUrlInput         ← API 地址输入框
│   └── ModelNameInput      ← 模型名称输入框
├── PromptConfigSection     ← 翻译设置区域
│   └── SystemPromptInput   ← 系统提示词多行文本框
├── AboutSection            ← 关于信息区域
└── ActionButtons           ← 保存/恢复默认按钮
    ├── 保存设置
    └── 恢复默认
```

## 6. 配置项存储结构

```typescript
interface AppConfig {
  apiKey: string;           // API Key（加密存储）
  apiUrl: string;           // API 地址
  modelName: string;        // 模型名称
  systemPrompt: string;     // 系统提示词
}
```

存储 Key：`appConfig`，使用 `chrome.storage.local.set/get` 读写。

## 7. 配置校验规则

| 字段 | 校验规则 | 错误提示 |
|------|---------|---------|
| API Key | 非空 | "API Key 不能为空" |
| API 地址 | 非空，且为合法 URL | "请输入有效的 API 地址" |
| 模型名称 | 非空 | "模型名称不能为空" |
