# 弹窗页面（Popup）—— 布局与实现步骤

## 1. 页面概述

插件弹窗是用户点击浏览器工具栏图标后弹出的主要交互界面。弹窗宽度固定为 **420px**，高度自适应（最大 **600px**），包含三个核心区域：状态栏、内容展示区、操作按钮区。

弹窗共有 5 种状态视图，根据当前处理阶段切换显示。

---

## 2. 状态 1：空状态（空闲等待）

当用户首次打开插件或上次翻译结果已被清除时显示。

```
┌──────────────────────────────────────┐
│  ◈ 网页翻译助手                        │
├──────────────────────────────────────┤
│                                      │
│                                      │
│           ┌──────────────────┐        │
│           │   翻译当前页面     │        │
│           └──────────────────┘        │
│                                      │
│        点击按钮，一键提取并            │
│        翻译当前英文文章内容            │
│                                      │
│                                      │
├──────────────────────────────────────┤
│  ⚙ 设置                              │
└──────────────────────────────────────┘
```

**模块构成：**
- **顶部标题栏**：插件名称 + 图标
- **中央操作区**：主按钮"翻译当前页面"，居中显示
- **底部导航**："设置"入口，点击跳转设置页
- **提示文字**：简要说明功能

│  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━    │

│                                      │
│  正在从页面中提取标题、正文、            │

- **操作按钮**：重新翻译、前往设置页

## 7. 弹窗组件树

```
App.tsx
├── StatusBar.tsx          ← 根据状态显示不同图标和文字
├── TranslationView.tsx    ← 集成 md-wx MarkdownRenderer
│   └── MarkdownRenderer   ← 来自 md-wx 包
│       ├── markdown       ← prop: 翻译结果字符串（动态更新）
│       ├── showSettings=false
│       ├── enableCopy=false
│       ├── enableThemeSwitch=false
│       ├── enableViewModeToggle=false
│       └── defaultViewMode='mobile'
└── ActionButtons.tsx      ← 根据状态显示不同按钮组合
    ├── 空状态：无按钮
    ├── 提取中：无按钮
    ├── 翻译中：复制 / 重新翻译 / 取消
    ├── 完成：  复制 / 重新翻译 / 下载
    └── 错误：  重新翻译 / 前往设置
```
