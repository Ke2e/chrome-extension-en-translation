# 侧边栏页面（Side Panel）—— 布局与实现步骤

## 1. 页面概述

插件侧边栏是用户点击浏览器工具栏图标后，在浏览器右侧打开的侧边栏。侧边栏**高度撑满整个浏览器窗口**，宽度由 Chrome 侧边栏决定（默认约 300px，用户可拖拽调整）。包含三个核心区域：状态栏、内容展示区（弹性撑满剩余空间）、操作按钮区。

侧边栏共有 5 种状态视图，根据当前处理阶段切换显示。

---

## 2. 状态 1：空状态（空闲等待）

当用户首次打开插件或上次翻译结果已被清除时显示。

```
┌──────────────────────┐
│  ◈ 网页翻译助手       │  ← 顶部标题栏
├──────────────────────┤
│                      │
│     ┌──────────┐     │
│     │ 翻译当前页面│    │
│     └──────────┘     │
│                      │
│  点击按钮，一键提取   │
│  并翻译当前英文文章   │
│                      │
│                      │  ← 内容区弹性撑满
│                      │
├──────────────────────┤
│  ⚙ 设置              │  ← 底部固定
└──────────────────────┘
```

**模块构成：**
- **顶部标题栏**：插件名称，渐变背景
- **中央操作区**：主按钮"翻译当前页面"，居中显示
- **底部导航**："设置"入口，点击跳转设置页
- **提示文字**：简要说明功能

## 7. 侧边栏组件树

```
App.tsx
├── StatusBar.tsx          ← 根据状态显示不同图标和文字
├── TranslationView.tsx    ← 集成 md-wx MarkdownRenderer
│   └── MarkdownRenderer   ← 来自 md-wx 包
│       ├── markdown       ← prop: 翻译结果字符串（动态更新）
│       ├── showSettings=false
│       ├── enableCopy=false
│       ├── enableThemeSwitch=false
│       ├── enableViewModeToggle=false
│       └── defaultViewMode='mobile'
└── ActionButtons.tsx      ← 根据状态显示不同按钮组合
    ├── 空状态：无按钮
    ├── 提取中：无按钮
    ├── 翻译中：复制 / 重新翻译 / 取消
    ├── 完成：  复制 / 重新翻译 / 下载
    └── 错误：  重新翻译 / 前往设置
```

## 10. 侧边栏布局要点

- **高度撑满全屏**：`html, body { height: 100% }`，`#root` 和 `.popup` 均使用 `display: flex; flex-direction: column` 垂直撑满
- **内容区弹性伸缩**：`.popup__body` 设为 `flex: 1; overflow-y: auto; min-height: 0`，翻译结果较少时收缩，内容较多时撑满并滚动
- **标题栏与底部固定**：`.popup__header` 和 `.popup__footer` 设为 `flex-shrink: 0`，不随内容滚动
- **翻译展示区自适应**：`.translation-view` 设为 `flex: 1; overflow-y: auto; min-height: 0`，始终占满可用空间
- **宽度自适应**：不设固定宽度，由 Chrome 侧边栏容器宽度决定，用户可拖拽调整
